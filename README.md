# 🎾 Disk Tennis Game

Покращена тенісна гра з сучасною графікою та фізикою, створена на React з використанням Canvas API.

## ✨ Особливості

- **Покращена графіка**: 3D ефекти, градієнти, тіні та світіння
- **Анімовані елементи**: Хмари, след м'яча, ефекти ударів
- **Реалістична фізика**: Гравітація, відбиття, тертя
- **Інтуїтивне керування**: Джойстик, кнопки стрибка та удару
- **Адаптивний дизайн**: Працює на мобільних пристроях та десктопі
- **ШІ суперник**: Розумний штучний інтелект з різними рівнями складності

## 🚀 Швидкий старт

### Встановлення залежностей
```bash
npm install
```

### Запуск в режимі розробки
```bash
npm run dev
```

### Збірка для продакшену
```bash
npm run build
```

### Попередній перегляд збірки
```bash
npm run preview
```

## 🎮 Керування

- **🕹️ Джойстик**: Рух гравця вліво/вправо
- **⬆️ Кнопка стрибка**: Стрибок для досягнення високих м'ячів
- **💥 Кнопка удару**: Потужний удар для швидких подач
- **👆 Тап по екрану**: Подача м'яча

## 🛠️ Технології

- **React 18** - Основний фреймворк
- **Canvas API** - Графіка та анімація
- **Tailwind CSS** - Стилізація
- **Vite** - Збірка та розробка
- **PostCSS** - Обробка CSS
